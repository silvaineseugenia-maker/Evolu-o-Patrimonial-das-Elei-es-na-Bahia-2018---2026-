# Evolu-o-Patrimonial-das-Elei-es-na-Bahia-2018---2026-
Em períodos eleitorais, a declaração de bens é essencial para a transparência. Este projeto investiga a evolução patrimonial dos candidatos na Bahia em 2026 com dados de 2018, 2022 e 2024. O objetivo é analisar a trajetória dos bens ao longo dos pleitos usando estatística e visualização de dados para identificar variações e discrepâncias.
